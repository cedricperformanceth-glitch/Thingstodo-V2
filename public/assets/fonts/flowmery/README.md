## License status

The supplied 1001Fonts FFC license allows Flowmery to be used free of charge for both personal and commercial use, including business websites and mobile apps. It also explicitly allows embedding in a web or mobile app and conversion to webfont formats, provided the font is not otherwise modified.

However, the same license states that the font may not be sold or **published** without written permission from the respective author. Because the Things To Do Atlas GitHub repository is public, the raw `.ttf` is intentionally **not committed to this repository**. This avoids republishing the font file itself while preserving its licensing record and project reference.
